HACKII PANEL SYSTEM - FINAL PACKAGE

Structure:
- public/index.html : frontend
- server.js         : Express server
- package.json      : Node dependencies/scripts
- data/uids.json    : server-side UID store (starts empty)

Run:
1. npm install
2. npm start

The frontend is served by server.js from public/index.html.
UID data is stored in data/uids.json.
